# Demo Project

This is a small, entirely fictional demo project. It only exists to carry a
synthetic commit history (2014-2016) with intentionally messy committer
names/emails and a few deliberate change-coupling patterns, generated by
[demo-repo-gen](https://github.com/feststelltaste/demo-repo-gen).

None of the names, email addresses or commit messages in this history refer
to real people or organizations.
